Senast uppdaterad 17 november 2026.

Vad appen gör

Appen är ett privat verktyg för en enda användare, ägaren. Den körs lokalt på ägarens dator och använder Google Sheets API för att läsa och lägga till rader i ett kalkylblad som ägaren själv äger.

Vilka data som används

  • Innehållet i ägarens eget kalkylblad, för att undvika dubbletter och lägga till nya rader.
  • Transaktioner från ägarens egen kortexport, som skrivs in i samma kalkylblad.

Lagring och delning

Google-data lagras inte någon annanstans än i ägarens eget Google-konto och på ägarens egen dator. Data skickas inte till tredje part, säljs inte och används inte för reklam eller för att träna AI-modeller. Åtkomsttoken sparas lokalt med begränsade filrättigheter.

Återkalla åtkomst

Åtkomsten kan när som helst återkallas på myaccount.google.com/permissions.
